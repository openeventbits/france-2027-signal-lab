# Candidate Bluesky mapping review — 17 October 2026

Reviewed the full **75-candidate canonical registry**: **6 accepted mappings; 69 unmapped**. Unmapped means FR27 did not establish sufficiently verified official personal/campaign identity, not that an account does not exist.

## Method and boundaries

Inspected 146 candidate-site/profile URL targets (102 returned page content; 44 attempts failed), covering all 75 candidates. Targets came from the prior registry-specific website review and included personal/campaign home, contact and organizational-profile pages. A successful HTTP response does not certify a page as official: parked, repurposed, unrelated and disclaimer-bearing domains were rejected. First-party website link inspection is identity research only; no Bluesky HTML, third-party analytics or search snippets supply production metrics.

Exact first-party profile links were resolved with `com.atproto.identity.resolveHandle` on `https://public.api.bsky.app/xrpc/`. Each accepted DID document was fetched through the official PLC directory and confirmed both the returned DID and `alsoKnownAs: at://<reviewed handle>`. François Ruffin qualifies through the custom handle matching his independently established official personal domain, with bidirectional identity agreement; no outbound website link is claimed for him. No fuzzy actor search is used.

Identity review made seven exact resolveHandle attempts plus one confirmation of Benjamin Lucas’s failure (8 XRPC requests), and six successful PLC DID-document requests. The live profile collection is separate and occurs only after offline tests pass. Mapping pins DIDs; handles are reviewed aliases and may later change.
