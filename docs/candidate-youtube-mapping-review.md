# YouTube mapping review — correction pass, 17 October 2026

## Scope and method

Re-reviewed **all 71 previously unmapped candidates**, preserving the original four mappings. Result: **75 registry candidates; 19 mapped; 56 unmapped; 15 newly accepted**. Unmapped does not mean no YouTube presence.

Discovery started with canonical registry identities and their Wikipedia/Wikidata website hints, followed by candidate-specific official-site discovery. Discovery metadata, search snippets and channel-name similarity were never accepted as account identity evidence. The review checked 187 URL targets, including unsuccessful attempts and discovery pages: personal/campaign homes, social/footer links, video pages, contact/about pages and candidate-specific organizational profiles. Unavailable, parked or unrelated domains are recorded rather than treated as proof of absence.

Exact first-party `/channel/`, `/@handle`, `/c/` and `/user/` links are admissible. Legacy URL form alone is never grounds for rejection. Exact handles were resolved through official YouTube Data API v3 `channels.list(forHandle=...)`. For legacy links, only the exact URL canonical/channel identity metadata was read to resolve the stable ID; official `channels.list` then validated it. Platform metrics were not scraped. No fuzzy `search.list` or candidate-name API search was used. Runtime continues to use pinned UC IDs only; no resolver, schema, collector or workflow change was needed.

Party/movement sources qualify only when they identify the individual account, with deterministic corroboration where needed. Generic party, parliamentary-group, institutional, media, supporter and repost accounts are excluded. All snapshot statistics come solely from the official Data API.
